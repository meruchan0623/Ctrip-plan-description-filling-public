# 翻译件操作说明

1. 在本机浏览器登录自己的携程供应商账号，打开程序并刷新登录态。
2. 下载任务、详情和规格模板，按自己的商品、APN、流量及安装规则填写；公开模板中的数字和文本为示例。
3. 导入本地模板，填写自己有权限的 productId，选择目标语言。
4. 先预载并检查差异、套餐映射、目标语言和要修改的字段。
5. 确认后传出草稿或执行界面所选操作；失败时先导出报告检查原因。

供应商 ID、对接系统 ID、供应商套餐 ID、价格和库存都应由自己账号提供。详细配置见项目 README 的“自定义配置与首次使用”。

不要分享登录态、真实业务模板、抓包或报告。遇到权限/登录错误，应停止写入并刷新登录态。
